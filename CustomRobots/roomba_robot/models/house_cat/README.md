Cat mesh and animations from "Animal Pack Vol.2" by Quaternius, released as
CC0 at https://opengameart.org/content/animated-animales-low-poly

The legs were baked from IK in Blender 3.3 and the IK bones removed, since gz
can't load animations of bones outside the skin. gz also ignores the actor
skin scale, so the DAE files set the unit to 0.11 m to get a real cat size.
